# Engineering Projects Archive

This repository collects selected academic engineering projects and supporting documentation from earlier coursework. It is kept as a reference archive for embedded programming, microcontroller work, and project documentation.

## Contents

- **Simple calculator project** — C++ source archive, development phases, compilation and testing instructions, and final documentation.
- **Arduino implementation** — archived Arduino source package for the calculator project.
- **Phase visualization** — documentation and visual material describing the project development process.
- **Supporting PDFs** — abstracts, development notes, and project results.

## How to use the archive

1. Start with Compiling and testing Instructions.pdf for the build and test procedure.
2. Extract the relevant ZIP archive before opening the source files.
3. Read the project PDFs for the design context and development phases.

The files are preserved as an academic archive. Original project artifacts and document filenames are retained for traceability.
